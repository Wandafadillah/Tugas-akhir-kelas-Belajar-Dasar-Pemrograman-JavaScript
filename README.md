# Belajar Dasar Pemrograman JavaScript - Final Assessment

Repositori ini berisi berkas submission untuk tugas akhir (Final Assessment) kelas Belajar Dasar Pemrograman JavaScript. Proyek ini mencakup tugas coding wajib untuk memenuhi syarat kelulusan dan tugas opsional untuk mendapatkan nilai optimal.

## 📌 Struktur Project & Status Pengerjaan

Di bawah ini adalah daftar tugas yang ada di dalam folder `final-assessment`. 

### 🛑 Tugas Wajib (Mandatory)
*Reviewer akan menolak submission jika terdapat kesalahan pada bagian ini.*
- [ ] **01-writing-comments** — Latihan penulisan komentar kode yang baik.
- [ ] **02-code-style** — Penerapan standar dan gaya penulisan kode JavaScript (linting/formatting).
- [ ] **03-writing-test** — Pembuatan unit testing untuk memastikan kode berjalan sesuai ekspektasi.

### 🌟 Tugas Opsional (Optional)
*Dikerjakan untuk mendapatkan nilai akhir yang maksimal.*
- [ ] **optional-04-oop** — Implementasi Object-Oriented Programming (Inventory & Item).
- [ ] **optional-05-recursive** — Penyelesaian masalah matematika dengan fungsi rekursif (Factorial & Fibonacci).
- [ ] **optional-06-full-coverage-testing** — Pembuatan automated testing dengan cakupan pengujian menyeluruh (100% coverage).
- [ ] **optional-07-real-world-scenario** — Penyelesaian studi kasus nyata sistem manajemen order/pesanan.

*Catatan: Ubah tanda `[ ]` menjadi `[x]` jika tugas pada folder tersebut sudah selesai Anda kerjakan.*

---

## 💻 Cara Menjalankan Proyek di Lokal

1. **Clone Repositori**
   ```bash
   git clone https://github.com
   ```
2. **Buka Folder Proyek**
   Buka aplikasi VSCode, lalu pilih *Open Folder* dan arahkan ke folder `final-assessment`.
3. **Membaca Instruksi**
   Buka berkas `instruksi.md` di setiap sub-folder tugas. Gunakan pintasan **`Ctrl + Shift + V`** di VSCode untuk mengaktifkan *Markdown Preview* agar instruksi lebih mudah dibaca.
